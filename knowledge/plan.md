# 線上陌生人猜謎網站計畫

## 願景

打造一個讓陌生人能即時配對、一起玩猜謎的線上網站。每局由網站提供一個主題，兩位玩家分別擔任出題者與猜題者；猜題者可以自由提問，出題者在聊天室回答。猜題者可隨時提交正式答案。猜中後交換角色並開始新一輪，讓雙方都能體驗出題與猜題。

## 目前狀態

- 階段：前端雛形與部署設定已完成，GitHub repository 和 Pages 發布待處理。
- 已完成可在單一瀏覽器互動的展示原型；配對對象、問答回覆與答案判定目前由示範流程模擬。
- 尚未連接真人即時配對、跨訪客聊天室或共享遊戲狀態服務。
- GitHub Actions Pages workflow 已加入專案；repository 尚未建立，網站尚未發布。
