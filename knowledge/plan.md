# 二選一共同點遊戲計畫

最後整理：2026-11-20

## 願景

做一個讓玩家透過二選一問答發現共同點的網站。玩家可以匿名快速開始，也可以使用 Instagram、Facebook、Google、X 或 Threads 登入；再選擇建立房間邀請朋友，或加入隨機配對。雙方回答相同題目後揭曉答案、查看共同點，並能回顧過往對局、找出最有默契的玩家。遊戲結束後，玩家可把結果製成直式分享卡，經本人確認後分享到 Instagram 限時動態。

產品核心是主題配對與問答遊戲，不是聊天網站。前端需清楚、易讀、適合手機使用；後端負責登入、配對、房間同步、結果及歷史紀錄的權限與保存。

## 目前狀態

- **階段：** 互動原型與第一輪瀏覽器版可用性檢查已完成；Supabase 隨機配對、邀請房間及個人歷史 migration 草稿已建立。原型已有首頁、主題選擇、示範配對、五題作答、逐題揭曉及結果頁。
- **已驗證：** Chrome 模擬 320、360、390、768、1024、1440px 寬度時，首頁沒有水平溢出；以鍵盤在三種手機寬度完成五題流程。已改善選項字級、觸控尺寸、焦點提示及作答狀態語意。
- **仍是模擬：** 對方答案來自瀏覽器範例資料。尚未提供真實登入、建立／加入房間、真人隨機配對、跨裝置同步、遊戲歷史或共同點統計。結果頁已可產生 1080×1920 PNG，支援系統分享面板及下載備援；尚未在 iOS／Android 實機確認 Instagram 交接。
- **後端：** `supabase/migrations/` 已包含即時對局、隨機配對、邀請房間、雙人歷史摘要及查詢 RPC 草稿；尚未建立 Supabase 專案、套用或執行驗證。尚無線上資料庫、Auth、Realtime 或已驗證的 RLS。
- **資料政策：** 真人對局房間及原始答案保留到結束後 24 小時，另存玩家各自可查詢、可刪除的對局摘要 90 天；統計只計最近 90 天。這是目前採用的 MVP 預設，migration 擴充草稿已完成，尚未套用或部署驗證。
- **登入與社群：** 已確認產品範圍包含匿名登入及 Instagram、Facebook、Google、X、Threads；尚未設定 OAuth provider 或驗證各平台流程。Instagram 與 Threads 的官方登入方式及 Supabase 自訂 provider 可行性仍須確認。
- **前端設計：** 已完成第一輪整體字級、留白、按鈕及主題選項版面整理，並加入房間、配對等待和歷史空狀態的操作預覽；需重跑窄螢幕檢查，真實成功／逾時狀態與後端資料仍待串接。
- **發布：** 功能分支的 Pages workflow 已推送並觸發，但 GitHub 因 github-pages 環境保護規則禁止此分支部署。需確認是否將此分支加入允許清單，再重新部署。
- **工作區：** 原型位於 `site/`，可直接開啟 `site/index.html` 操作，不需安裝套件或建置。
- **產品方向：** 遠端 `main` 保留原有猜謎版本；本分支依本計畫製作二選一共同點遊戲，詳見 [knowledge/decision.md](decision.md)。

## 已確認方向

### 遊戲、房間與配對

- 每局由兩位玩家回答同一主題的選擇題；原型使用五題，每題兩個選項。
- 玩家可建立房間並分享加入方式，也可進入隨機配對佇列。預設房間碼為 12 位英數代碼，等待加入 10 分鐘，單一帳號同時只能參加一個進行中的房間。
- 雙方完成當題作答後才揭曉答案；完成後呈現共同答案及結果。
- 一場遊戲使用一個主題；玩家可指定主題或選擇隨機主題。
- 不把自由聊天作為主要玩法。

### 登入

- 提供匿名登入及 Instagram、Facebook、Google、X、Threads 社群登入。
- 匿名玩家後續連結社群身分時，需保留同一遊戲帳號與可延續的歷史紀錄。
- 各 provider 的官方 OAuth/OIDC 支援、callback、審核及 Supabase 設定列為實作前驗證項目；client secret 不放在 GitHub Pages 前端。

### 歷史紀錄與共同點統計

- 登入玩家可查詢自己最近 90 天已完成的對局，並查看共同選擇與對局結果。
- 歷史紀錄只有本人可見；玩家可以刪除單筆紀錄，刪除帳號時清除本人紀錄。
- 最有共同點的玩家按最近 90 天的共同答案比例排序；至少完成 3 局才納入排名，並顯示對局數及共同答案總數。

### 結果分享

- 結果頁提供 9:16 直式分享卡，呈現主題、共同選擇和品牌識別，不包含登入資料或聯絡資訊。
- 玩家主動按下分享，由手機系統分享面板選擇 Instagram 並自行確認發布；不自動代替玩家發文。
- 瀏覽器不支援分享檔案或沒有 Instagram 分享目標時，提供 PNG 下載。
